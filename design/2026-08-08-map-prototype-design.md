# アニメ聖地巡礼マップ プロトタイプ設計

日付: 2026-08-08
ステータス: 承認済み（実装フェーズへ）

## 1. 背景・目的

「海外観光客向けアニメ聖地巡礼スポットマップ」アプリの企画の一環として、これまでリサーチしたアニメ聖地・関連施設データ（`research/anime-pilgrimage-spots.md`）を、Google Mapsのような見た目のよいマップ上でビジュアル検証するためのWebプロトタイプを作成する。

- 位置づけ: Webプロトタイプ（Artifactとして公開するデモ）。本番アプリの技術スタック（React Native / Flutter 等）はまだ決定しない。
- 目的: マップUI/UXの方向性検証。実データ・実装可否ではなく、体験の良し悪しを確認する。
- 表示言語: 日本語のみ（多言語対応は本番実装時に別途検討）。

## 2. スコープ

### 含むもの
- `research/anime-pilgrimage-spots.md` に登場する全スポット（約30件、20作品弱）を地図上にプロット
  - 通常作品の聖地（君の名は。、スラムダンク、鬼滅の刃 等）
  - 関連施設（ワンピース熊本の像群、こち亀両さん像、ポケふた 等）
  - マイナー・カルト人気作品（頭文字D、ガールズ&パンツァー、あの花 等）
- スポット種別3分類でのタグ付けと色分け表示
  1. 実際の舞台・ロケ地（scene）
  2. 像・モニュメント・記念施設（monument）
  3. 着想元・モデル地（非公式、ファン間の通説を含む）（inspiration）
- 作品名フィルター（複数選択）
- スポット種別フィルター
- 都道府県クリックでのズーム／全国表示へのリセット
- ピンクリックでの詳細カード表示（スポット名・作品名・種別・概要・所在地・Googleマップへの外部リンク）
- 都道府県ズーム時のサイドパネル（その県のスポット一覧、カードクリックで地図ピンをハイライト）

### 含まないもの（本番実装時に検討）
- 多言語対応（英語・繁体中国語・韓国語等）
- 実データベース・API連携（今回は静的データを埋め込み）
- 現在地連動・ルート案内
- 写真・口コミ・混雑度・アクセス時刻表等の付加情報
- ユーザー投稿・レビュー機能

## 3. データモデル

```
Spot {
  id: string
  name: string            // スポット名
  anime: string            // 作品名
  prefecture: string        // 都道府県
  lat: number
  lng: number
  type: "scene" | "monument" | "inspiration"
  description: string       // 概要（1〜2文）
  mapsQuery: string         // Googleマップ検索用クエリ文字列
}
```

- データソースは `research/anime-pilgrimage-spots.md` の内容を実装時に構造化データへ変換する。
- 各スポットの緯度経度は既知の地名・施設名から実装時に補完する（現地座標データは未取得のため、実装フェーズで調査・埋め込みを行う）。
- `mapsQuery` は詳細カードの「Googleマップで開く」リンク生成に使用し、`https://www.google.com/maps/search/?api=1&query=<mapsQuery>` へのリンクとして実装する。単純な外部リンク遷移であり、Artifactの通信制限（fetch/XHR禁止）には抵触しない。

## 4. 地図描画方式

- Artifactは実行時に外部ホストへ通信できない（CSP制約）ため、Google Maps APIやOpenStreetMapタイルなど外部地図タイルは使用しない。
- 都道府県境界データは、実装時にパブリックドメインの日本行政区域GeoJSON（例: dataofjapan/land 等）を取得・簡略化し、SVGパスとして静的に埋め込む。
- ピンの座標は、都道府県境界と同一の投影法（簡易な等距円筒図法をSVG座標系に合わせてスケーリングしたもの）で変換し、地図上の正しい相対位置に配置する。
- 都道府県クリック時は、その都道府県のバウンディングボックスへSVGのviewBoxをアニメーション遷移させてズームする。「全国表示に戻る」ボタンで元のズームレベルに復帰する。

## 5. インタラクション仕様

- **フィルターパネル**（画面上部 or サイド）
  - 作品名: 複数選択可能なチェックリスト／ドロップダウン
  - スポット種別: 3種類のトグルチップ（色分けバッジと連動）
- **ピン表示**
  - 種別ごとに色・アイコンを変える
  - 都道府県ズーム中は該当県のピンを強調表示、他県のピンは淡色化
- **詳細カード**
  - ピンクリックでフローティングカードを表示
  - 内容: スポット名、作品名、種別バッジ、概要、所在地、「Googleマップで開く」リンク（新規タブ）
- **都道府県ズーム＋サイドパネル**
  - ズーム中はサイドパネルにその都道府県のスポット一覧をカード形式で表示
  - サイドパネルのカードをクリックすると、対応する地図上のピンをハイライト

## 6. ビジュアルデザイン方針

- dataviz スキルの配色ガイドラインに準拠し、スポット種別ごとのカテゴリカルカラーを設計する。
- ライト／ダーク両テーマに対応する（Artifactの規約に準拠）。
- 背景の地図はニュートラルな単色〜淡いグラデーションとし、ピンと詳細カードのUIで情報を際立たせるミニマルで上品なトーンにする。
- レスポンシブ対応（PC幅を主軸としつつ、スマホ幅でも操作可能なレイアウトにする）。

## 7. 技術構成

- 単一のHTMLファイルとして実装し、Artifactとして公開する。
- 外部ライブラリ・CDNへの依存は行わず、必要なJS/CSSはすべてインライン化する（Artifactの自己完結制約に準拠）。
- 都道府県境界SVGパス・スポットデータはビルド時（実装作業時）に生成し、静的な定数として埋め込む。

## 8. 未決事項・リスク

- 都道府県境界データの簡略化精度と、ピン投影の位置ズレは実装しながら調整が必要。
- スポット数が多いため（30件超）、都道府県が密集するエリア（関東・近畿等）でのピン重なり対策（クラスタリング等）は実装時の様子を見て検討する。
